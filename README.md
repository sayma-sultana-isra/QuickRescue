# QuickRescue 🚨
A voice-activated emergency alert system for rapid response and enhanced personal safety.

## 🔧 Features
- Voice-triggered emergency activation (e.g., keyword: "Help")
- Panic button alternative trigger
- Automatic location sharing
- Live audio recording and sending
- SQLite database for user/auth info
- Admin panel to monitor and review incidents

## 🧑‍💻 Tech Stack
- JavaFX (headless)
- Multithreading
- Socket Programming
- SQLite Database
- SceneBuilder

## 🗂 Project Structure
- `server/`: Core functionality (panic, audio, voice)
- `database/`: SQLite models and services
- `audio/`: Audio recorder and sender logic
- `utils/`: Utility classes (e.g., location fetcher)

## 📦 Setup
```bash
git clone https://github.com/sayma-sultana-isra/QuickRescue.git
cd QuickRescue
```

Use IntelliJ to open and run the project. Make sure JDK is installed and paths are configured.
